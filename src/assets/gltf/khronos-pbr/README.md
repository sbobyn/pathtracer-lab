# Khronos glTF transmission references

These unmodified binary glTF assets come from the
[Khronos glTF Sample Assets repository](https://github.com/KhronosGroup/glTF-Sample-Assets)
and are included as focused interoperability references.

- `CompareTransmission.glb` — [source and license](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CompareTransmission)
- `CompareVolume.glb` — [source and license](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CompareVolume)
- `DispersionTest.glb` — [source and CC BY 4.0 attribution](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/DispersionTest), created by Ed Mackey
- `DragonDispersion.glb` — [source and attribution](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/DragonDispersion); Stanford dragon mesh, Morgan McGuire conversion, and Adobe cloth backdrop
- `DragonAttenuation.glb` — [source and attribution](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/DragonAttenuation); Stanford dragon mesh, Morgan McGuire conversion, and Adobe cloth backdrop

The Compare assets are published under CC0 apart from the Khronos trademark.
The dragon license notices are preserved beside their GLBs. See each linked
upstream directory for authoritative attribution and license details. The
Stanford dragon geometry is limited to research and other non-commercial use;
credit the Stanford Computer Graphics Laboratory in any README or social post.
